TRANSPARENT SOUND DESIGN

How data becomes sound

Data value

Numerical value from the selected data series.

Pitch

Higher normalized value → higher tone frequency.

Time

Each data point plays in chronological order.

Volume

Audio volume is controlled through the volume slider.

WHY THIS MATTERS

Earth science for more people.

This project demonstrates how Earth science data can be explored through visualization and sound. It aims to make data patterns more accessible, including for people with visual impairments.
